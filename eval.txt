═══════════════════════════════════════

  kernel:

  ┌────
  │   Imagen 5×5                 Kernel 3×3
  │   0  0  1  0  0              1  0 -1
  │   0  1  2  1  0              1  0 -1
  │   1  2  3  2  1              1  0 -1
  │   0  1  2  1  0
  │   0  0  1  0  0
  └────

  ┌────
  │   Kernel de convolucion              
  │  -5 0 5
  │  -6 0 6 
  │  -5 0 5
  └────


2.0.1 Tareas
╌╌╌╌╌╌╌╌╌╌╌╌

  1. Con *stride = 1* y *padding valid* (sin relleno), ¿cuál es el
     tamaño del mapa de salida? 
     3x3

  2. Calcula *solo* el valor de la esquina superior izquierda del mapa
     (la primera posición del filtro). Muestra la suma de productos.
     ┌────
     │ esquina spr izq           
     │  0 0 1              1 0 -1

     │  1 2 3              1 0 -1
     └────

3 Pregunta 2 — Contar pesos

    *todas* las entradas a una capa densa de *64 neuronas* (sin bias por
    ahora).
  • *Modelo B (CNN):* una `Conv2D' con *16 filtros* de *3×3*,
    `padding''same'=, sobre la misma imagen (con bias: un bias por
    filtro).


3.0.1 Tareas
╌╌╌╌╌╌╌╌╌╌╌╌

    formula: nun entradas * num neuronas
    entradas = 28 * 28 * 3 = 2352
    pesos = 2352 * 64 = 150528 
    la capa tiene 150528 pesos

  2. ¿Cuántos parámetros tiene la Conv2D del Modelo B? (pesos de kernels

    pesos de kernels = 3 * 3 * 3 * 16 = 432
    biases = 16 
    = 432 + 16 
    = 448 parámetros

     porque cuando comparte los mismos pesos en la imagen aprende patrones sin importar la localizacion y usa parametros para ya no tener que memorizar datos

6.0.1 Tareas

     Esta muy seguro de una preduccion incorrecta ya que tiene un 85% a tornado y un 5% a la clase incorrecta

8 Pregunta 7 — Dropout: ¿dónde y para qué?
══════════════════════════════════════════

  En `CNNriesgo' hay `Dropout(0.5)' después del pooling y otra vez antes
  de la salida.


8.0.1 Tareas
╌╌╌╌╌╌╌╌╌╌╌╌

  1. Durante *entrenamiento*, ¿qué hace Dropout(0.5) en una capa densa
     de 32 neuronas (en promedio cuántas “sobreviven” por paso)?
    Desactiva aleatoriamente el 50% de las neuronas durante cada paso del entrenamiento 

  2. Durante *inferencia* (`predict'), ¿se apagan neuronas al azar? ¿Por
     qué sí o no?
    no, durante la inferencia dropout esta desactivado y se utilizan todas las neuronas y el escaldo de las activaciones se gestiona durante el entrenamiento

  3. Un compañero pone Dropout *solo* en la última época “para que no se
     sobreajuste al final”. ¿Tiene sentido? Critica la idea en 3–5
     líneas.
     no porque el sobreajuste puede ocurrir en cualquier parte del entrenamiento y dropout debe aplicarse durante el entrenamiento para regularizar el aprendizaje y usarlo unicamente en la ultima epoca no va corregir los sobreajustes que ocurrieron en las epocas anteriores

13 Notas al pie (fórmulas útiles — no sustituyen el razonamiento)
═════════════════════════════════════════════════════════════════

  • Salida convolución (un eje), padding valid: \(\lfloor (N - K)/S
    \rfloor + 1\)
  • Padding same + stride 1: salida ≈ mismo \(N\)
  • Parámetros Conv2D: \(K_h \cdot K_w \cdot C_{in} \cdot C_{out} +
    C_{out}\) (si hay bias)
  • Parámetros Dense: \(n_{in} \cdot n_{out} + n_{out}\) (si hay bias)
